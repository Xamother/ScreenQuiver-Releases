# Accessibility

ScreenQuiver uses native Windows controls. Both editions provide light, dark
and system themes, keyboard-accessible controls and configurable shortcuts for
common layout actions. Global shortcuts are optional.

Accessibility work is ongoing. Complete Narrator, high-contrast, text-scaling
and keyboard-only testing has not been established across both editions. The
project does not claim WCAG conformance or accessibility certification.

If a barrier prevents you from using the app or documentation, please
[open an issue](https://github.com/Xamother/ScreenQuiver-Releases/issues/new?template=bug_report.yml)
and include:

- The edition, app version and Windows version.
- The assistive technology, scaling or contrast settings involved.
- The control or task that is difficult to use and the expected behaviour.

Screenshots or recordings are optional; redact personal information. Reports
are welcome even if you cannot provide all of these details. Improvements are
reviewed as time permits.
